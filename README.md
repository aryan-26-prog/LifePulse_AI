<section>
<h2>🚀 What is LifePulse AI?</h2>

<div class="card">
<p>
<strong>LifePulse AI</strong> is a next-generation humanitarian intelligence platform that 
combines <strong>real-time environmental data, community health signals, and AI-driven risk analysis</strong> 
to help governments, NGOs, and volunteers respond faster during health crises and disasters.
</p>

<p>
The platform continuously analyzes air quality, weather conditions, human health inputs, 
and historical trends to generate <strong>actionable risk insights</strong> instead of raw data.
</p>
</div>
</section>

<section>
<h2>🎯 Problem Statement</h2>

<div class="card">
<ul>
<li>No unified real-time community health monitoring system</li>
<li>Delayed disaster & pollution-related health alerts</li>
<li>Poor coordination between NGOs, volunteers, and citizens</li>
<li>Static dashboards that don’t predict or explain risk</li>
</ul>
</div>
</section>

<section>
<h2>💡 Our Solution</h2>

<div class="card">
<p>
LifePulse AI transforms raw environmental and health data into 
<strong>live risk intelligence</strong> using AI-powered analysis, 
smooth AQI trend modeling, and human vulnerability assessment.
</p>

<p>
Instead of showing numbers, the platform explains:
<strong>What’s happening, why it matters, and what action is needed.</strong>
</p>
</div>
</section>

<section>

<section>
<h2>⚙️ Installation & Setup</h2>

<div class="card">
<h3>Frontend</h3>
<code>
cd frontend  
npm install  
npm run dev
</code>

<h3>Backend</h3>
<code>
cd backend  
npm install  
npm start
</code>

<h3>AI Engine</h3>
<code>
cd ai-engine  
pip install -r requirements.txt  
uvicorn main:app --reload
</code>
</div>
</section>
